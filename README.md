# ETM Car-Solution — Proposition B (éditorial motorsport)

Site vitrine one-page statique. Aucune dépendance, aucun build : `index.html` suffit.

## Déploiement
Pousser ce dossier sur GitHub → Vercel → Add New Project → preset **Other** → Deploy.

## En quoi c'est une autre proposition (pas une variante de couleur)
| | Version en ligne | Proposition B |
|---|---|---|
| Accueil | Carrousel plein écran, 5 slides | Écran coupé en deux : typographie géante à gauche, photo à droite |
| Prestations | 8 cartes en grille | Index éditorial numéroté 01→08, avec aperçu photo qui suit le curseur |
| Titres | Sora, casse normale | Archivo 800, capitales, très grand, interlettrage serré |
| Galerie | Mosaïque figée | Bande à défilement horizontal |
| Arguments | 4 cartes | Phrase-manifeste + liste à filets |
| Coins | Arrondis | Angles droits (plus technique, plus haut de gamme) |
| Chiffres | Sous le carrousel | Bande à 4 colonnes séparées par des filets |

## Formulaire
Les demandes partent vers **etm.carsolution@gmail.com** via FormSubmit.
Au premier envoi, FormSubmit envoie un mail d'activation à cette adresse : cliquer le lien **une seule fois**.

## Photos
Incrustées en base64 dans `index.html` (visibles partout, même hors ligne) et en WebP dans `assets/photos/`.
Visuels de démonstration issus de templates open source : à remplacer par les vraies photos de l'atelier avant mise en ligne.

## Logo
`assets/logo/` — bouclier et wordmark, SVG + PNG, fond noir et fond blanc.
Reconstitutions d'après la carte de visite et le flyer : à remplacer par les fichiers sources du client s'il les a.
